# Jyothir Gosh — Portfolio

Personal portfolio website for **Jyothir Gosh**, a developer and editor based in Kerala, India.

## Focus
- Web development
- Video editing
- Graphic design
- Creative technology
- BCA / Cybersecurity learning

## Built with
- React
- TypeScript
- Vite
- Tailwind CSS
- GSAP / Lenis

## Projects
The portfolio includes selected work such as **Malabar Agro Park**, **AXYNO**, and other personal projects.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is generated in `dist/`.

## GitHub Pages

For a personal site using the repository name `jyothirgosh.github.io`, deploy the Vite project from GitHub Pages after pushing the source code. GitHub Actions can be used to build the project and publish the `dist` output.
